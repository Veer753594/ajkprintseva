Auto Print Agent Setup

Customer website se order aayega, admin payment verify karke approve karega aur Windows PC agent printer queue me job bhejega — browser Print dialog ke bina.

How it works

1. Customer Order

Customer file upload karta hai, print type/pages choose karta hai aur payable amount dekhta hai.

2. Payment

UPI app, QR ya Cash. Admin payment verify karke Paid karta hai.

3. Admin Approval

Paper type save karke Approve for Auto Print click karein.

4. Silent Print

Windows agent job claim karke configured printer par background me print karta hai.

Shop PC requirements

  • Windows 10/11
  • Printer installed and tested in Windows
  • Internet connection
  • Node.js 20+ for source version
  • SumatraPDF for dialog-free PDF/image printing
  • LibreOffice optional for Word/Excel/PowerPoint conversion to PDF

Agent setup

  1. Netlify → Environment variables → create AGENT_KEY.
  2. Copy agent/config.example.json to config.json.
  3. Set the same Agent Key, live website URL and exact Windows printer name.
  4. Run npm install then npm start, or build the EXE.
  5. Keep the agent PC on and connected.

Important printing notes

Browser window.print() cannot reliably press the final system Print button. This final build does not depend on the browser print dialog. The Windows agent uses SumatraPDF command-line printing with printer, color/B&W, copies, duplex, A4 and tray settings. Your physical paper/tray must still be loaded correctly.
